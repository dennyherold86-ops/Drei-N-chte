# ❤️ Drei Nächte

Eine interaktive Musik-Webseite für den Song **„Drei Nächte“**.

## Features

- Intro-Sequenz mit sanftem Übergang
- Audio-Player mit Play/Pause
- Fortschrittsring um das Cover
- Circular Audio Visualizer
- Cover-Rotation während der Wiedergabe
- Dynamischer Hintergrund
- Parallax-Effekt
- Floating Lights
- Floating Hearts
- Responsive Layout
- Cinematisches Finale mit Textanimation

---

```
Drei-Nächte

├── index.html

    ├── cover.png
    ├── Drei Nächte.mp3
    └── favicon.png
```

---

## Voraussetzungen

Es wird kein Build-System benötigt.

Ein moderner Browser genügt.

Getestet mit:

- Chrome
- Edge
- Firefox

---

## Installation

Projekt herunterladen.

Assets in den Ordner **assets** legen.

Anschließend einfach die Datei

```
index.html
```

im Browser öffnen.
